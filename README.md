## 📚 2024 Hex 切版班 Week 02 主線任務 - 內容訂閱網站

本專案為六角學院切版班第二週主線任務，依據課程提供的 Figma 設計稿進行網頁切版練習。  
任務重點在於熟悉 Bootstrap 的格線系統與客製化變數設定，並運用 Sass 7-1 架構提升樣式維護性。

🔗 [🔍 前往 Demo](https://itsdaiyy.github.io/2024-hex-week6-website/)

---

###🎯 專案學習重點

- 使用 Bootstrap 5 的格線系統實作響應式排版
- 客製化 Bootstrap SCSS 變數，調整主題色系與元件樣式
- 遵循 Sass 7-1 架構進行樣式模組化，提升維護性與可讀性

---

### 🛠 使用技術

- **樣式設計 |** Bootstrap 5, SCSS (Sass), Sass 7-1 Pattern
- **專案部署 |** GitHub Pages
